Notes

About this directory

  • All mocks render the same canonical screen — a sent-campaign report — with identical fake data, so comparisons are direct.
  • Each mock is a single self-contained .html file. No build step, no dependencies beyond Google Fonts.
  • Chrome / navigation / utility pages use the canonical light theme defined in this file's :root. Direction mocks define their own themes.
  • Serve locally with npm run mocks.
